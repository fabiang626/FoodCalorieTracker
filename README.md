# Food Calorie Tracker 
Author: Fabian Galindo 

## Project Purpose 
The Food Calorie Tracker is a web application that allows users to record foods consumed throughout the day and track their total calorie intake.

## Technologies Used

- HTML
- CSS
- Javascript
- Visual Studio Code
- Git
- Github

## Prerequisites 
Following software is required: 

- Web browser
- Visual Studio Code

## Installation

1. Download Github repository

## Running the Application

1. Open the project in Visual Studio Code
2. Locate file named 'index.html'.
3. run the program and open in a web browser
4. The Food Calorie Tracker dashboard appears

## Sprint 1 Functionality

1. Open the application
2. Enter food name.
3. Enter a calorie amount greater than 0.
4. Click **Add Food**.
5. Verify that food appears in the food log.
6. Verify that total calorie count updates.
7. Submit and empty food name and error message appears.
8. Submit 0 calories and error message appears.

## Known Limitations

- Users cannot set calorie goals yet.
- Users cannot track protein, carbohydrates, or fat.
- Search and filtering features are not implemented.
- Data is only stored in the browser's local storage.
